## 📌 Описание

**Bank App** – это Python-приложение для анализа транзакций, которые находятся в Excel-файле. Приложение умеет 
генерировать JSON-данные для веб-страниц приложения, формировать Excel-отчеты и предоставляет ряд других сервисов.

### Запуск


```bash
# Установите зависимости с помощью Poetry
poetry install

# Запустите приложение
poetry run python main.py
```
Для использования внешних API (например, для получения курсов валют или котировок акций), добавьте
ключи API в файл .env (создайте его на основе example_.env.py).

## 🌐 Подробное описание веб-страниц

### 🌐 Главная страница

Отображает данные за период с начала месяца по указанную дату.

- **Приветствие**: "Доброе утро", "Добрый день", "Добрый вечер" или "Доброй ночи" в зависимости от времени.
- **Данные по картам**: последние 4 цифры карты, общая сумма расходов, кешбэк (1 рубль на 100 рублей).
- **Топ-5 транзакций**: самые крупные расходы за период.
- **Курс валют**: актуальные обменные курсы.
- **Котировки акций S&P 500**: актуальные цены акций.

Валюты и акции для отображения на веб-страницах задаются в отдельном файле пользовательских настроек 
user_settings.json

### 🌐 Страница "События"

Формирует анализ расходов и поступлений за заданный период (неделя, месяц, год или весь доступный период).

- **Расходы**:
  - Общая сумма расходов.
  - Топ-7 категорий расходов с их суммарными значениями.
  - Суммы переводов и снятий наличных.
- **Поступления**:
  - Общая сумма поступлений.
  - Топ-7 категорий поступлений.
- **Курс валют и котировки акций**: данные за указанный период.

## 🛠️ Подробное описание сервисов

### 🛠️ Выгодные категории повышенного кешбэка

Позволяет определить наиболее выгодные категории для выбора кешбэка за заданный месяц и год.

- Входные данные: дата транзакций, год, месяц.
- Выходные данные: JSON с суммой возможного кешбэка по категориям.

### 🛠️ Инвесткопилка

Позволяет откладывать деньги за счет округления трат.

- Входные параметры: список транзакций, месяц, лимит округления (10, 50 или 100 рублей).
- Выходные данные: сумма, отложенная в «Инвесткопилку».

### 🛠️ Простой поиск

Позволяет найти транзакции по ключевым словам в описании или категории.

- Входные параметры: строка поиска.
- Выходные данные: JSON с транзакциями, содержащими запрос.

### 🛠️ Поиск по телефонным номерам

Позволяет найти транзакции, содержащие телефонные номера в описании.

- Выходные данные: JSON с транзакциями, где обнаружены номера телефонов.

### 🛠️ Поиск переводов физическим лицам

Находит переводы физическим лицам на основе категории **Переводы** и формата имени **Имя Ф.**.

- Выходные данные: JSON со всеми транзакциями переводов физлицам.

## 📊 Подробное описание отчетов

### 📝 Декоратор для отчетов

Все функции отчетов используют декоратор, который автоматически записывает результат в файл.

- Без параметра — имя файла генерируется автоматически на основе имени модуля, содержащего декорируемую функцию
и текущего времени 
- С параметром — задается имя файла вручную.

### 📊 Траты по категории

Формирует отчет по заданной категории за последние 3 месяца.

- **Входные данные**: датафрейм с транзакциями, название категории, опциональная дата.
- **Выходные данные**: сумма трат за последние 3 месяца.

### 📊 Траты по дням недели

Формирует отчет о средних тратах по дням недели за последние 3 месяца.

- **Входные данные**: датафрейм с транзакциями, опциональная дата.
- **Выходные данные**: средняя сумма трат на каждый день недели.

### 📊 Траты в рабочий/выходной день

Анализирует средние траты в будние и выходные дни за последние 3 месяца.

- **Входные данные**: датафрейм с транзакциями, опциональная дата.
- **Выходные данные**: средние суммы трат в рабочие и выходн

│── README.md            # Документация
